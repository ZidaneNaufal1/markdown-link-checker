# Kebijakan keamanan

Perbaikan keamanan diterapkan pada rilis terbaru dan branch `main`.

Jangan unggah credential, dokumen internal, path sensitif, atau laporan dari
proyek pribadi ke issue publik. Gunakan contoh sintetis saat mereproduksi bug.
Laporan dapat memuat nama file dan target link; tinjau sebelum membagikannya.

Jika fitur GitHub **Report a vulnerability** tersedia, gunakan jalur tersebut.
Jika belum tersedia, buat issue minimal untuk meminta kontak privat tanpa detail
kerentanan atau informasi sensitif. Jalur ini belum menjanjikan SLA respons.

Program tidak melakukan permintaan jaringan dan tidak membaca target di luar
root yang ditetapkan. Root hanya boleh berupa folder yang memang ingin diperiksa.
